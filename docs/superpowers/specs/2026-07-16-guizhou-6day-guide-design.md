# 贵州 6 日旅行攻略设计规格

## 目标

在现有 React + Vite 项目上完成一份可离线部署、适合打印为 PDF 的贵州 6 日自由行攻略。页面以“黔蓝手作旅行簿”视觉稿为唯一基准，采用米白纸张、靛蓝纹样、朱红点缀、摄影拼贴和旅行手记排版。

## 固定路线

- D1：高铁抵达贵阳，按抵达时间选择甲秀楼、青云市集。
- D2：贵阳往返黄果树，游览陡坡塘、天星桥、大瀑布，突出门票与水帘洞实名预约。
- D3：贵阳北至荔波站，游览小七孔并住荔波。
- D4：荔波包车或拼车至西江，下午及夜间游苗寨并住寨内。
- D5：上午及下午继续体验西江，傍晚经凯里南返回贵阳，晚上抵达并住贵阳。
- D6：上午游览文昌阁、电台街等贵阳城区小景点；午餐后取行李，下午乘高铁返程。若 D1 已游甲秀楼，D6 不重复安排。

## 页面与技术

- 保留 `DayPlan` 数据结构及现有语义化页面组件。
- 固定锚点为 `#overview`、`#itinerary`、`#sights`、`#transport`、`#checklist`。
- 本地图片资源不依赖运行时网络；最终交付位于 `dist/`。
- 桌面端采用旅行杂志式错落布局，390px 手机端采用单列时间轴且无横向滚动。
- 打印时隐藏交互控件，完整保留行程、清单及预约提示。
- 票价、车次和开放时间不写死，出发前通过官方渠道复核。

## 阶段验收

1. 内容、数据与项目基线。
2. 首屏与路线视觉。
3. 完整攻略与移动端。
4. 打印、构建与最终视觉 QA。

每个阶段完成后更新 `PROJECT_PROGRESS.md` 并暂停，等待用户检查。
