# 贵州六天攻略全量迁移设计

## 目标

将 `D:/workbuddy/project/2026-07-16-16-34-33/贵州6天攻略_完整整合版.md` 作为唯一内容事实来源，完整迁移到现有“黔蓝手作旅行簿”网站。保留现有 React + Vite 应用、视觉语言、响应式布局、A4 打印能力、GitHub Pages 主发布与 OpenAI Sites 备用发布；不新建网站，不保留与源攻略冲突的旧版行程。

## 范围与内容完整性

网页必须呈现源文档中的全部信息，而非摘要或改写：

- 广州往返贵阳的高铁/飞机选择、价格、时间、接驳和 12306 候补提示。
- 路线速览、六日每日时间表、每段交通方案、价格、耗时、推荐与避坑。
- 每晚住宿地点、所有具名酒店或民宿建议、评分、区位、亮点与参考价格。
- 每日餐饮、具体店名、菜品、价格、夜市与伴手礼建议。
- 所有行前衣物、必带物、预算、预约事项、全程交通费用对比、住宿速览、通用避坑和时效声明。
- D2 上帝视角的五步进入路线、大瀑布/水帘洞的省力与常规方案；D6 黔灵山省力路线，以及青岩古镇备选方案。

内容可为阅读体验拆分为结构化段落、表格和清单，但不得改变事实含义、删减源信息或用旧版信息填补空缺。

## 信息架构与组件边界

- `src/data/guide.js`：站点元数据、城际交通、行前总览、预算、预约、交通对比、住宿速览、通用饮食与避坑数据。
- `src/data/days.js`：六天的路线节点、时间表、交通分段、住宿、餐饮、每日提示，以及 D2/D6 的长步骤说明。
- `src/components/RouteMap.jsx`：依据 `days` 展示六个新节点与新的连续路线说明；继续使用现有真实地图底图，必要时只替换对应地图素材。
- `src/components/TripOverview.jsx`：展示全部行前清单、含广州往返成本说明的预算与六项预约。
- `src/components/DayChapter.jsx`：逐日展示时间表、交通、住宿、餐饮和提醒；支持源文档中的编号步骤、可选方案和提示段落。
- `src/components/TripSummaries.jsx`：展示源文档六段交通费用对比、六晚住宿速览、吃喝省钱及全程避坑。
- `src/App.jsx`：更新首屏文案、日程配图映射、官方核验区域和原攻略时效声明；保持导航、打印按钮和页面锚点。

数据层只存事实与展示顺序；组件只负责语义化渲染。避免把路线、价格或酒店文案分散写入多个组件。

## 视觉与兼容性

- 延续米白纸张、黔蓝墨色、朱红点缀、靛蓝织物和摄影拼贴的既有视觉，不做无关重设计。
- 六日地图需要清晰表达下司和朗德的连续转场；桌面保留地图标注，手机保留可读的垂直节点列表。
- 1440px、1024px 与 390px 不得产生横向溢出；复杂表格在手机端仍必须逐项可读。
- 打印为 A4 纵向；隐藏交互控件，并避免每日卡片、地图和表格行在不合理位置分页。
- 继续使用本地 PNG/WebP 图片和相对资源路径；不引入在线字体、在线核心图片或新的 UI 框架。
